# NEU WakeUp 课表导出（Android）

面向东北大学新版金智教务系统的 Android 课表导出工具。App 使用学校官方登录页面完成登录，然后在手机端读取教务系统接口，将课程表导出为 WakeUp 可导入的 CSV，也可以导出为通用日历 ICS。

本项目受 [CreamPig233/neu_wisedu2wakeup](https://github.com/CreamPig233/neu_wisedu2wakeup) 启发，将原项目的课表解析思路移植到 Android 端，适合不方便使用电脑脚本的手机用户。

> [!CAUTION]
> 新教务系统仍在持续调整，本工具只提供辅助导出能力。课程、考试、调停课等信息请始终以教务系统官方页面为准。

## 功能

- 使用官方教务登录页，不在 App 内收集或保存账号密码。
- 自动检测网络模式，支持校园网直连和外网 WebVPN 访问。
- 支持校园网 HTTP 页面加载，避免 `ERR_CLEARTEXT_NOT_PERMITTED`。
- 登录状态校验成功后自动隐藏登录页，减少误触和界面干扰。
- 解析普通课程、实验课，并合并同一时间地点下的多教师记录。
- 读取 `exams.do` 考试安排，可将考试作为特殊课程加入导出结果。
- 支持导出 WakeUp CSV，保存位置默认引导到系统 `Documents` 目录。
- 支持导出 ICS，可导入系统日历或其他日历应用。
- 导出完成后自动弹出打开方式，便于直接选择 WakeUp 或日历应用导入。

## 导出内容

点击“导出课表”后，可以在弹出的面板中选择导出类型和导出内容。

CSV 支持：

- 仅课表
- 课表+考试

ICS 支持：

- 仅课表
- 课表+考试
- 仅考试

CSV 下“仅考试”会被禁用，因为 WakeUp 的 CSV 导入更适合新建或覆盖一整张课表，单独导入考试容易误操作覆盖已有课表。

## 考试安排

考试会被转换成课程表中的一条特殊课程：

- 课程名称：`[考]课程名 考试类型`
- 教师字段：`座位号：xx号`
- 地点字段：`考场，xx号`
- 周数字段：来自教务系统返回的 `week`

考试时间不直接使用原始考试时间，而是贴近到最近的课程节次，用来提前提醒。例如浑南校区考试 `10:10-12:10` 会映射到第 2-4 节，也就是 `9:25-12:10`。

作息时间按校区判断。普通课程会优先使用教务接口中的校区字段；考试地点如果无法判断校区，当前按浑南校区作息时间处理。

## 使用方法

1. 打开 App，等待网络检测完成。
2. 在下方官方登录页面完成教务系统登录。
3. 点击“检测登录状态”，确认登录有效并自动填充当前学期代码。
4. 如需导出其他学期，手动修改学期代码，例如 `2025-2026-2`。
5. 点击“获取课表”，等待提示解析到的课程数量和考试数量。
6. 点击“导出课表”，选择 `CSV` 或 `ICS`，再选择导出内容。
7. 保存文件后，在弹出的打开方式中选择 WakeUp 或日历应用。

如果 CSV 自动被文档编辑器或其他应用打开，通常说明系统已经给 CSV 设置过默认打开方式。此时可以在 WakeUp 中手动选择“从 CSV 导入”，再选中导出的文件。WakeUp 官方说明：[如何导入 CSV](https://wakeup.fun/doc/import_from_csv.html)。

## 数据来源

当前主要读取以下教务系统接口：

- `currentUser.do`：检查登录状态和读取当前学期。
- `courses.do`：读取普通课程。
- `getMyScheduleDetail.do`：补充课程详情、校区信息和实验课。
- `exams.do`：读取考试安排。
- `getTermWeeks.do`：读取学期起始日期，用于 ICS 日期换算。

## 隐私与安全

- 不接入第三方后端。
- 不上传账号、密码、Cookie、课表或考试安排到开发者服务器。
- 所有教务请求都由用户手机直接发往学校教务系统或学校 WebVPN。
- App 只复用官方登录页面产生的登录态来读取课程和考试数据。

- Android Studio
- JDK 17+
- Gradle 9.3.1

- Compile SDK 36

常用构建命令：

```bash
./gradlew :app:assembleDebug
```

## 已知限制

- 教务系统接口字段可能继续变化，若学校调整返回结构，解析逻辑可能需要同步更新。
- 考试校区无法从接口明确读取时，会默认按浑南校区时间表映射。
- CSV 面向 WakeUp 导入格式；ICS 面向日历应用，两者对提醒、覆盖和重复导入的行为不同。
